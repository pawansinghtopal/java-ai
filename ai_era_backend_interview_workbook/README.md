# AI-Era Backend Engineering Interview Workbook

A static, interactive study workbook for backend engineering interviews, especially deployment ownership, GitLab branching/CI/CD, versioning, AI-assisted coding workflows, context windows, hallucinations, and production reasoning.

## Files

- `index.html` — main page and workbook content
- `style.css` — responsive styling, light/dark themes, and print styles
- `app.js` — question data, search/filter, progress tracking, checklist, and mock interview interactions

## How to open

1. Keep all three files in the same folder.
2. Double-click `index.html` to open it in a modern browser (Chrome, Edge, Firefox, Safari).
3. No build step, server, or internet connection is required for the workbook itself. The source/reference links need internet access.

## Features

- Search and filter interview questions
- Expand/collapse answers
- Mark questions as understood and track progress
- Light/dark theme
- Project deployment audit checklist with text export
- Mock interview question mode
- Print or save as PDF from the browser

## Notes

Progress and theme preference are saved in browser `localStorage` where available. Browser privacy settings may restrict persistence for pages opened via `file://`. If that happens, use the same browser profile or serve the folder through a static host/local server.
